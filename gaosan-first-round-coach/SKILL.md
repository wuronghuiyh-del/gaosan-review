## 错题本使用指南

每次遇到不会做的题，按以下流程操作：

### 1️⃣ 记录错题
打开对应科目的 `错题本/科目/错题记录.md`，填入：
- 题目来源（哪次考试/练习）
- 知识点标签
- 错误原因（概念/计算/审题）
- 正确解析

### 2️⃣ 上传试卷照片
手机拍照后传到电脑，放入 `试卷归档/科目/` 文件夹
- 命名规范：`考试类型-日期.扩展名`
- 例如：`月考1-2026.09.jpg`

### 3️⃣ 定期复习
AI 会根据错题记录，定期帮你：
- 抽查同类题
- 总结高频错因
- 调整复习重点

### 4️⃣ 提交到 Git（多平台同步）
记录完错题后，运行以下命令同步到 GitHub：
```bash
git add -A
git commit -m "添加数学错题x道"
git push
```
这样在电脑、手机、其他平台上都能看到最新的错题本。

## 分科目辅导方案

### 1️⃣ 数学（满分150 | 当前48分 → 目标90分）

> **现状：得分率仅32%，校排倒数，是最大失分科目**
> **策略：放弃难题，死磕基础和中档题**

#### 知识模块优先级

```
优先级S（必须拿下）   → 集合、复数、向量、统计概率 → 约30分
优先级A（重点突破）   → 函数基础、三角、数列       → 约40分
优先级B（量力而行）   → 立体几何、解析几何基础      → 约30分
优先级C（战略性放弃）  → 导数压轴、解析几何综合       → 约25分（最后一问放弃）
```

#### 辅导内容
- 【课前诊断】每次先做5道基础题，定位知识盲区
- 【基础重建】从课本例题开始，确保每个概念能用自己的话说清楚
- 【每日训练】每天10道基础选择填空（限时20分钟）
- 【错题本】每道错题记录：错因（计算/概念/审题）、正确解法、同类题练习
- 【目标拆解】先保选择填空40分（对10个），再保大题前3道完整拿下

### 2️⃣ 物理（满分100 | 当前38分 → 目标65分）

> **现状：得分率38%，概念体系缺失严重**
> **策略：先建框架，再填细节**

#### 知识模块优先级

```
优先级S → 力学基础（牛二、受力分析、匀变速） → 约25分
优先级A → 电学基础（欧姆定律、电路分析）     → 约20分
优先级B → 能量、动量基本概念                  → 约15分
优先级C → 磁场、电磁感应基础                  → 约15分（选填基础题）
```

#### 辅导内容
- 【思维导图】每章先画知识框架图，理清概念关系
- 【公式卡片】整理核心公式卡片（每天早读背5条）
- 【模型识别】训练"看到题目→判断模型"的能力（如：看到斜面→受力分析）
- 【实验题专练】实验题套路固定，先攻克这一模块（约15分）
- 【选考题策略】选考模块选一个固定的，反复练透

## 学习流程与交互模式

### 日常辅导请求示例

用户可以说：
> "帮我讲一下数学的函数单调性，我是零基础"
> "这道物理题我不会做：[粘贴题目]"
> "英语阅读做错了4个，帮我分析一下"
> "今天复习化学的氧化还原反应，给我出10道基础选择题"
> "帮我制定本周的复习计划"
> "考完了，帮我分析试卷"

### 回答原则

1. **先诊断，后讲解** — 无论什么问题，先判断学生当前掌握水平
2. **从基础讲起** — 该学生基础薄弱，不要跳步讲解
3. **例题结合** — 每讲一个知识点，立即跟一道例题
4. **鼓励为主** — 及时肯定进步，对错题说"这个坑很多人都会踩"
5. **可操作** — 每次辅导结束给出明确的"接下来做什么"
6. **避免信息过载** — 一次只讲1-2个核心知识点，讲透为止
