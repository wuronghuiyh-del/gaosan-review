1 乙醇燃料电池（酸性） 对应错题 #1

对应错题：CO气体传感器 — 介质条件判断

题目：一种乙醇（C2H5OH）燃料电池，以 H₂SO₄ 溶液 为电解质，正极通入 O₂。

  1. 写出该电池的 负极反应式（C₂H₅OH 被氧化为 CO₂）
  2. 写出该电池的 正极反应式
  3. 若电路中转移了 1.2 mol 电子，消耗的 O₂ 在标准状况下的体积是多少？

(1) 负极：

C₂H₅OH + 3H₂O − 12e⁻ → 2CO₂ + 12H⁺
🔑 C₂H₅OH 中 C 平均价态 −2 → CO₂ 中 +4，每个C升6价，2个C共升12价，失12e⁻。酸性条件用 H⁺ 和 H₂O 配平。

(2) 正极：

3O₂ + 12H⁺ + 12e⁻ → 6H₂O
🔑 酸性条件：O₂ + 4H⁺ + 4e⁻ → 2H₂O，乘以3配平电子数

(3) 电子转移计算：

由正极反应：O₂ ~ 4e⁻，n(O₂) = 1.2 ÷ 4 = 0.3 mol
V(O₂) = 0.3 × 22.4 = 6.72 L ✅
2 锂离子电池（放电+充电） 对应错题 #2

对应错题：Ni-H₂充电电池 — 充放电判断

题目：一种锂离子电池的总反应为：

LiCoO₂ + 6C ⇌ Li₁₋ₓCoO₂ + LiₓC₆

（放电时从左→右，充电时从右→左）

  1. 放电时，哪一极是负极？写出负极反应式。
  2. 充电时，Li⁺ 向哪一极移动？
  3. 该电池的离子交换膜应该是哪种类型？

(1) 放电时负极：

❌ 6C + xLi⁺ + xe⁻ → LiₓC₆ —— 这是正极反应！
注意：放电时 负极失电子，LiₓC₆ 中的 Li 应该失去电子变成 Li⁺
✅ 负极：LiₓC₆ − xe⁻ → 6C + xLi⁺
✅ 正极：Li₁₋ₓCoO₂ + xLi⁺ + xe⁻ → LiCoO₂

(2) 充电时：

充电是放电的逆过程，Li⁺ 从正极材料中脱出，向负极移动（回到石墨中）✅

(3) 交换膜类型：

Li⁺ 是阳离子，所以是 阳离子交换膜 ✅（允许 Li⁺ 通过）
3 电解水催化机理 + 燃料电池匹配 对应错题 #3

对应错题：PEM燃料电池+催化机理 — 图-电极匹配

题目：研究某电解水催化剂（析氧反应 OER）的催化机理，得到下图所示的能量变化：

能量 ↑ ╱╲ TS₂ │ ╱ ╲ ╱╲ ╱╲ 产物 │ ╱ ╲ ╱ ╲ ╱ ╲ │ ╱ ╲ ╱ ╲ ╱ ╲ │ ╱ ╲ ╱ ╲══╱ ╲ │╱ ╲╱ ╲ ╲ │ TS₁ 中间体₁ 中间体₂ │ 反应物 └──────────────────────────────→ 反应进程

图中显示 OER 反应：2H₂O → O₂ + 4H⁺ + 4e⁻ 的过程中，有两个过渡态 TS₁ 和 TS₂。

  1. 该反应的决速步是哪一步？
  2. 如果将该催化剂用于 氢氧燃料电池的正极，是否可以？为什么？
  3. 该催化剂若用于 PEM燃料电池，电极反应是什么？

(1) 决速步：

TS₂ 对应的步骤（能垒更高，是快速步）✅

(2) 可以用于正极！

因为 OER（析氧反应）2H₂O → O₂ + 4H⁺ + 4e⁻ 是 电解水 的反应
它的逆反应 O₂ + 4H⁺ + 4e⁻ → 2H₂O 正是 燃料电池正极反应
好的 OER 催化剂通常也是好的 ORR（氧还原）催化剂 ✅

(3) PEM燃料电池正极反应：

O₂ + 4H⁺ + 4e⁻ → 2H₂O ✅
（PEM 是酸性环境，与本题酸性条件一致）
4 CH₃OH 催化重整 + 直接甲醇燃料电池 对应错题 #4

对应错题：CO₂-CH₄催化重整 + 甲烷燃料电池 — 综合多图

第一部分：催化重整

题目：CH₃OH(g) + H₂O(g) → CO₂(g) + 3H₂(g)   ΔH = +49 kJ/mol

  1. 该反应是吸热还是放热？升温对平衡有何影响？
  2. 使用催化剂后，ΔH 会改变吗？为什么？

第二部分：直接甲醇燃料电池（KOH电解质）

以 CH₃OH 为燃料，KOH 为电解质 的燃料电池。

  1. 写出负极反应式（CH₃OH → CO₃²⁻）
  2. 写出正极反应式
  3. 陷阱题：若测得 5.6 L CH₃OH（气体，已汽化）完全反应，电路中转移了 0.75NA 个电子。判断此说法是否正确并说明理由。

第一部分

(1) ΔH > 0，吸热反应。升温使平衡 正向移动（有利于产氢）。

(2) 催化剂 不改变 ΔH！只改变活化能。

第二部分

(3) 负极：

CH₃OH + 8OH⁻ − 6e⁻ → CO₃²⁻ + 6H₂O
🔑 CH₃OH 中 C：−2价 → CO₃²⁻ 中 C：+4价，变化6e⁻
碱性条件，产物为 CO₃²⁻（不是CO₂！）

(4) 正极：

O₂ + 4e⁻ + 2H₂O → 4OH⁻
乘以 1.5 配平：1.5O₂ + 6e⁻ + 3H₂O → 6OH⁻

(5) 陷阱题分析：

❌ 说法错误！
CH₃OH ∼ 6e⁻（每个CH₃OH分子转移6个电子）
5.6 L ÷ 22.4 L/mol = 0.25 mol（在标准状况下）
n(e⁻) = 0.25 × 6 = 1.5 mol ≠ 0.75 mol ❌
错误原因：即使标准状况下，转移电子数应为 1.5NA，不是 0.75NA。
如果还没说明是标准状况，更是错上加错！
🎯 牢记：没标"标准状况"就不能用 22.4 L/mol！
