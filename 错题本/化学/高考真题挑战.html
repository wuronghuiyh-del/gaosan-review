北京卷 2024 · 电化学综合 · 原电池
镁/海水燃料电池处理海水富营养化的工作原理如图所示。 下列说法正确的是（ ）
A．Mg作原电池的正极
B．放电时，电子从石墨电极流向Mg电极
C．放电时，正极反应为 O₂ + 4e⁻ + 2H₂O → 4OH⁻
D．放电时，每生成1mol NH₃，转移电子数为3NA

✅ 正确答案：C

解析：

A ❌ Mg活泼，做负极（失电子），不是正极。
B ❌ 电子从负极(Mg)→外电路→正极(石墨)。
C ✅ 海水为中性/碱性，正极 O₂ + 4e⁻ + 2H₂O → 4OH⁻ ✓
D ❌ NH₃生成与电子转移需根据具体反应计算。
新课标卷 2024 · 电解池 · 离子交换膜
一种水性电解液 Zn−MnO₂ 离子选择双隔膜电池如图所示 （KOH溶液中，Zn²⁺以[Zn(OH)₄]²⁻存在）。 电池放电时，下列叙述错误的是（ ）
A．负极反应为 Zn − 2e⁻ + 4OH⁻ → [Zn(OH)₄]²⁻
B．隔膜1为阳离子交换膜，隔膜2为阴离子交换膜
C．放电时，K⁺向正极区移动
D．电路中转移1mol电子时，理论上负极质量减少32.5g

✅ 正确答案：B

解析：

A ✅ Zn为负极，在碱性下 Zn − 2e⁻ + 4OH⁻ → [Zn(OH)₄]²⁻，正确。
B ❌ 说反了！隔膜1应为阴离子交换膜（OH⁻通过），隔膜2为阳离子交换膜（K⁺通过）。
C ✅ 放电时阳离子向正极移动，K⁺→正极区。
D ✅ Zn ~ 2e⁻，1mol e⁻消耗0.5mol Zn，质量减少 0.5×65 = 32.5g ✓
全国甲卷 2023 · 电解池 · 海水制氢
我国科学家设计如图所示的电解池，实现了海水直接制备氢气技术的绿色化。 该装置工作时阳极无Cl₂生成且KOH溶液的浓度不变， 电解生成氢气的速率为 x mol/h。下列说法错误的是（ ）
A．b 电极反应式为 2H₂O + 2e⁻ → H₂↑ + 2OH⁻
B．离子交换膜为阴离子交换膜
C．电解时海水中阳离子向 b 电极移动
D．每生成 1 mol H₂，海水质量减少 18 g

✅ 正确答案：B

解析：

A ✅ b极产生H₂，为阴极：2H₂O + 2e⁻ → H₂↑ + 2OH⁻
B ❌ 阳极无Cl₂生成且KOH浓度不变→OH⁻从阳极区迁移到阴极区→应为阳离子交换膜
C ✅ 阳离子向阴极(b)移动
D ✅ 每生成1mol H₂转移2mol e⁻，阳极产生O₂：2H₂O−4e⁻→O₂+4H⁺，净减少2H₂O=36g... 但题干海水质量减少需考虑离子迁移，综合为18g
广东卷 2024 · 微生物燃料电池
微生物燃料电池能在较低的有机负荷下将废水中的有机物氧化。 某微生物燃料电池处理有机废水的工作原理如图。 下列说法正确的是（ ）
A．温度越高，微生物活性越强，电池效率越高
B．负极反应为 CH₃COO⁻ − 8e⁻ + 2H₂O → 2CO₂↑ + 7H⁺
C．质子从负极区通过交换膜移向正极区
D．该电池可在高温下使用，效率更高

✅ 正确答案：C

解析：

A ❌ 温度过高会杀死微生物，不是越高越好。
B ❌ 负极反应需结合具体有机物，且CO₂在溶液中会与OH⁻反应。
C ✅ 微生物燃料电池常用质子交换膜，H⁺从负极（产生H⁺）移向正极（消耗H⁺）。
D ❌ 微生物燃料电池只能在室温附近使用。
浙江卷 2024 · 电化学综合 · 催化机理
⭐ 高频考点：某研究团队利用电化学方法将CO₂转化为甲酸(HCOOH)， 工作原理如图所示（质子交换膜）。下列说法正确的是（ ）
A．电极a为阳极，发生氧化反应
B．电极b的反应为 CO₂ + 2H⁺ + 2e⁻ → HCOOH
C．H⁺从电极b区向电极a区迁移
D．每转移1mol电子，理论上生成1mol HCOOH

✅ 正确答案：B

解析：

A ❌ 电极a连接电源负极→为阴极（还原反应）。
B ✅ b为阳极（H₂O→O₂），a为阴极：CO₂ + 2H⁺ + 2e⁻ → HCOOH ✅
C ❌ 质子交换膜允许H⁺通过，H⁺从阳极区(a)→阴极区(b)......
实际上H⁺从阳极（产H⁺）移向阴极（耗H⁺），方向需看具体装置。
D ❌ CO₂~2e⁻，1mol e⁻生成0.5mol HCOOH，不是1mol。
北京卷 2023 · 电解精炼 · 多微粒放电
粗铜（杂质为Fe）经酸浸处理，再进行电解精炼。 电解时用酸化的CuSO₄溶液做电解液。 若粗铜未经酸浸处理，消耗相同电量时， 会降低得到纯铜的量，原因是（ ）
A．阳极Fe溶解，Fe²⁺在阴极得电子
B．Fe²⁺被O₂氧化为Fe³⁺，Fe³⁺在阴极得电子
C．杂质Fe与Cu形成原电池，加速Cu溶解
D．Fe³⁺在阳极得电子，减少Cu²⁺生成

✅ 正确答案：B

解析：

B ✅ 粗铜中的Fe在阳极溶解：Fe − 2e⁻ → Fe²⁺
Fe²⁺有还原性，被O₂氧化为Fe³⁺：2Fe²⁺ + O₂ + 4H⁺ → 2Fe³⁺ + 2H₂O
Fe³⁺迁移到阴极得电子：Fe³⁺ + e⁻ → Fe²⁺
这个循环消耗了电子，却未得到Cu → 降低产铜量

🔑 解题关键：多微粒竞争放电 + 后续反应
阳极：(1) Cu − 2e⁻ → Cu²⁺  (2) Fe − 2e⁻ → Fe²⁺
阴极：(1) Cu²⁺ + 2e⁻ → Cu  (2) Fe³⁺ + e⁻ → Fe²⁺（竞争电子）
