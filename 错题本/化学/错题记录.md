### 第1题 🔴 CO气体传感器 — 电极反应式

**题目：** 电化学CO气体传感器，电解质为 H₂SO₄ 溶液，写出正极反应式。

**我的错误答案：**
> O₂ + 4e⁻ + **2H₂O** = **4OH⁻** ❌
> （这是碱性条件下的写法！）

**正确答案：**
> O₂ + 4e⁻ + **4H⁺** = **2H₂O** ✅
> （酸性条件，H₂SO₄ 提供大量 H⁺）

**核心记忆：**

| 条件 | 正极（O₂还原） | 负极（CO氧化） |
|:---|:---|:---|
| **酸性** | O₂ + 4H⁺ + 4e⁻ → 2H₂O | CO + H₂O − 2e⁻ → CO₂ + 2H⁺ |

### 第2题 🔴 Ni-H₂ 充电电池（KOH电解质）

**题目：** KOH电解质可充电电池，H₂/Ni电极，下列说法错误的是？

**关键信息：**
- 电解质：**KOH**（碱性！）
- 电极a：H₂ + RuNi/C
- 电极b：NiO(OH)/Ni(OH)₂
- 有离子交换膜

**核心分析：**

#### ✅ 正确判断

| 状态 | 电极a（H₂侧） | 电极b（Ni侧） |
|:---|:---|:---|
| **放电**（电池供电） | **负极**：H₂ + 2OH⁻ − 2e⁻ → 2H₂O（氧化） | **正极**：NiO(OH) + H₂O + e⁻ → Ni(OH)₂ + OH⁻（还原） |
| **充电**（外界充电） | **阴极**：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原） | **阳极**：Ni(OH)₂ + OH⁻ − e⁻ → NiO(OH) + H₂O（氧化） |

#### ❌ 常见错误选项特征

1. **离子交换膜类型说错**
   - ~~阳离子交换膜~~ ❌ → **阴离子交换膜** ✅（OH⁻通过）

2. **电子流向说反**
   - 放电：e⁻ 从 **a(H₂)→外电路→b(Ni)**
   - 充电：e⁻ 从电源负极→a，b→电源正极

3. **pH变化判断错**
   - 放电时：**a侧H₂** OH⁻被消耗 → **pH↓**
   - 放电时：**b侧Ni** OH⁻生成 → **pH↑**

4. **充电时电极名称说反**
   - 充电时 a = **阴极**（还原），b = **阳极**（氧化）

### 第3题 🔴 PEM燃料电池 + 催化机理（多图综合题）

**题目：** PEM氢氧燃料电池，题干给出"O₂获得第一个电子是最慢步骤"，左图是催化循环（图a），中图是电池结构（电极Ⅰ/Ⅱ+PEM），右图是反应能量图。选项A说"负极反应的催化剂为图a中的催化剂ⅰ"。

**我的错误答案：**
> A. 负极反应的催化剂为图a中的催化剂ⅰ ❌

**正确答案：**
> 图a的催化循环对应的是**正极（O₂还原）**反应，不是负极 ✅

**分析过程：**

#### 三步分析法

| 步骤 | 判断 | 理由 |
|:---|:---|:---|
| **① 看反应复杂度** | 图a是多步催化循环 | 复杂反应 → O₂还原（4e⁻+4H⁺） |
| **② 匹配电极** | 多步循环 → **正极** | 负极H₂氧化是一步反应 |
| **③ 验证题干** | "O₂获得第一个电子最慢" | 与图a多步催化吻合 |

#### 结论

```
图a（催化循环，多步）  →  正极（O₂还原反应）  ✅
右图（简单反应）       →  负极（H₂氧化反应）  ✅
```

- [ ] 公式记错

### 第4题 🔴 CO₂-CH₄催化重整 + 甲烷燃料电池（多图综合题）

**知识点：** 该题包含两大块内容

#### 第一部分：CO₂ + CH₄ → 2CO + 2H₂（ΔH = +247 kJ/mol）

**核心考点：**

| 考点 | 说明 |
|:---|:---|
| **ΔH>0** | 吸热反应，升温有利正反应 |
| **催化剂作用** | 降低活化能，不改ΔH，不改平衡 |
| **决速步（RDS）** | 能量图上最高峰对应的步骤 |
| **Sn-Ni vs Pt-Ni** | 活化能低的催化活性更高 |

#### 第二部分：甲烷燃料电池（KOH电解质）

**电池反应：**

| 电极 | 反应式 |
|:---|:---|
| **负极**（CH₄氧化） | CH₄ + 10OH⁻ − 8e⁻ → CO₃²⁻ + 7H₂O |
| **正极**（O₂还原） | O₂ + 4e⁻ + 2H₂O → 4OH⁻ ✅（碱性条件） |

> 注意：碱性条件下 CH₄ 产物是 CO₃²⁻（不是CO₂），因为CO₂会与OH⁻反应！

**电子转移计算：**
- 1个 CH₄ 分子：C从−4价→+4价（CO₃²⁻中），**失8e⁻**
- 1 mol CH₄ → 8 mol e⁻

**⚠️ 气体体积陷阱（重要！）：**
- "11.2 L CH₄ 转移 4NA 电子"
- 必须说明 **"标准状况"** 才能用 22.4 L/mol
- 若未说明标况，11.2 L ≠ 0.5 mol，电子数不确定 ❌

**CO产率图分析：**
- 曲线 A 和 B 在约 600°C（W点）相交
- 低温：A催化活性高；高温：B催化活性高
