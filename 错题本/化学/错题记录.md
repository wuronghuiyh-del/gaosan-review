### 第1题 🔴 CO气体传感器 — 电极反应式

**题目：** 电化学CO气体传感器，电解质为 H₂SO₄ 溶液，写出正极反应式。

**我的错误答案：**
> O₂ + 4e⁻ + **2H₂O** = **4OH⁻** ❌
> （这是碱性条件下的写法！）

**正确答案：**
> O₂ + 4e⁻ + **4H⁺** = **2H₂O** ✅
> （酸性条件，H₂SO₄ 提供大量 H⁺）

- [ ] 公式记错
- [ ] 粗心大意
- [ ] 思路不对

**知识点标签：** 电化学、原电池、电极反应式、酸碱性介质

**核心记忆：**

| 条件 | 正极（O₂还原） | 负极（CO氧化） |
|:---|:---|:---|
| **酸性** | O₂ + 4H⁺ + 4e⁻ → 2H₂O | CO + H₂O − 2e⁻ → CO₂ + 2H⁺ |
| **碱性** | O₂ + 2H₂O + 4e⁻ → 4OH⁻ | CO + 4OH⁻ − 2e⁻ → CO₂ + 2H₂O |

### 第2题 🔴 Ni-H₂ 充电电池（KOH电解质）

**题目：** KOH电解质可充电电池，H₂/Ni电极，下列说法错误的是？

**关键信息：**
- 电解质：**KOH**（碱性！）
- 电极a：H₂ + RuNi/C
- 电极b：NiO(OH)/Ni(OH)₂
- 有离子交换膜

**核心分析：**

#### ✅ 正确判断

| 状态 | 电极a（H₂侧） | 电极b（Ni侧） |
|:---|:---|:---|
| **放电**（电池供电） | **负极**：H₂ + 2OH⁻ − 2e⁻ → 2H₂O（氧化） | **正极**：NiO(OH) + H₂O + e⁻ → Ni(OH)₂ + OH⁻（还原） |
| **充电**（外界充电） | **阴极**：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原） | **阳极**：Ni(OH)₂ + OH⁻ − e⁻ → NiO(OH) + H₂O（氧化） |

#### ❌ 常见错误选项特征

1. **离子交换膜类型说错**
   - ~~阳离子交换膜~~ ❌ → **阴离子交换膜** ✅（OH⁻通过）

2. **电子流向说反**
   - 放电：e⁻ 从 **a(H₂)→外电路→b(Ni)**
   - 充电：e⁻ 从电源负极→a，b→电源正极

3. **pH变化判断错**
   - 放电时：**a侧H₂** OH⁻被消耗 → **pH↓**
   - 放电时：**b侧Ni** OH⁻生成 → **pH↑**

4. **充电时电极名称说反**
   - 充电时 a = **阴极**（还原），b = **阳极**（氧化）

- [x] 审题不清

### 第3题 🔴 PEM燃料电池 + 催化机理（多图综合题）

**题目：** PEM氢氧燃料电池，题干给出"O₂获得第一个电子是最慢步骤"，左图是催化循环（图a），中图是电池结构（电极Ⅰ/Ⅱ+PEM），右图是反应能量图。选项A说"负极反应的催化剂为图a中的催化剂ⅰ"。

**我的错误答案：**
> A. 负极反应的催化剂为图a中的催化剂ⅰ ❌

**正确答案：**
> 图a的催化循环对应的是**正极（O₂还原）**反应，不是负极 ✅

**分析过程：**

#### 三步分析法

| 步骤 | 判断 | 理由 |
|:---|:---|:---|
| **① 看反应复杂度** | 图a是多步催化循环 | 复杂反应 → O₂还原（4e⁻+4H⁺） |
| **② 匹配电极** | 多步循环 → **正极** | 负极H₂氧化是一步反应 |
| **③ 验证题干** | "O₂获得第一个电子最慢" | 与图a多步催化吻合 |

#### 结论

```
图a（催化循环，多步）  →  正极（O₂还原反应）  ✅
右图（简单反应）       →  负极（H₂氧化反应）  ✅
```

**错因分析：**
- [x] 知识点没掌握 — 没理解多步催化对应的是O₂还原
- [ ] 计算错误
- [x] 审题不清 — 没结合题干"O₂得第一个电子最慢"判断
- [ ] 公式记错
- [ ] 粗心大意
- [x] 思路不对 — 应先做"图-电极匹配"再判断选项
