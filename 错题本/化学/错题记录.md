### 第1题 🔴 CO气体传感器 — 电极反应式

**题目：** 电化学CO气体传感器，电解质为 H₂SO₄ 溶液，写出正极反应式。

**我的错误答案：**
> O₂ + 4e⁻ + **2H₂O** = **4OH⁻** ❌
> （这是碱性条件下的写法！）

**正确答案：**
> O₂ + 4e⁻ + **4H⁺** = **2H₂O** ✅
> （酸性条件，H₂SO₄ 提供大量 H⁺）

**错因分析：**

- [ ] 计算错误
- [x] 审题不清 — 看到了 H₂SO₄ 但写反应时忘了
- [ ] 公式记错
- [ ] 粗心大意
- [ ] 思路不对

**知识点标签：** 电化学、原电池、电极反应式、酸碱性介质

**核心记忆：**

| 条件 | 正极（O₂还原） | 负极（CO氧化） |
|:---|:---|:---|
| **酸性** | O₂ + 4H⁺ + 4e⁻ → 2H₂O | CO + H₂O − 2e⁻ → CO₂ + 2H⁺ |
| **碱性** | O₂ + 2H₂O + 4e⁻ → 4OH⁻ | CO + 4OH⁻ − 2e⁻ → CO₂ + 2H₂O |

### 第2题 🔴 Ni-H₂ 充电电池（KOH电解质）

**题目：** KOH电解质可充电电池，H₂/Ni电极，下列说法错误的是？

**关键信息：**
- 电解质：**KOH**（碱性！）
- 电极a：H₂ + RuNi/C
- 电极b：NiO(OH)/Ni(OH)₂
- 有离子交换膜

**核心分析：**

#### ✅ 正确判断

| 状态 | 电极a（H₂侧） | 电极b（Ni侧） |
|:---|:---|:---|
| **放电**（电池供电） | **负极**：H₂ + 2OH⁻ − 2e⁻ → 2H₂O（氧化） | **正极**：NiO(OH) + H₂O + e⁻ → Ni(OH)₂ + OH⁻（还原） |
| **充电**（外界充电） | **阴极**：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原） | **阳极**：Ni(OH)₂ + OH⁻ − e⁻ → NiO(OH) + H₂O（氧化） |

#### ❌ 常见错误选项特征

1. **离子交换膜类型说错**
   - ~~阳离子交换膜~~ ❌ → **阴离子交换膜** ✅（OH⁻通过）

2. **电子流向说反**
   - 放电：e⁻ 从 **a(H₂)→外电路→b(Ni)**
   - 充电：e⁻ 从电源负极→a，b→电源正极

3. **pH变化判断错**
   - 放电时：**a侧H₂** OH⁻被消耗 → **pH↓**
   - 放电时：**b侧Ni** OH⁻生成 → **pH↑**

4. **充电时电极名称说反**
   - 充电时 a = **阴极**（还原），b = **阳极**（氧化）
