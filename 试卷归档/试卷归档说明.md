# 试卷归档说明

## 存放方式

### 方式一：拍照存档（推荐手机拍）

拍下试卷照片后，通过以下步骤保存到对应科目文件夹：

1. **手机拍照** — 清晰、端正
2. **传到电脑** — 微信/QQ发送文件助手 / USB数据线
3. **放入对应文件夹** — 如：`试卷归档\数学\月考1-2026.09.jpg`
4. **在 Git 中记录** — 运行 `git add -A && git commit -m "添加数学月考1试卷"`

### 方式二：电子版 PDF

如果学校发电子版试卷，直接放入对应科目文件夹：

```
试卷归档\
├── 数学\
│   ├── 月考1-2026.09.pdf
│   └── 期中-2026.11.pdf
├── 物理\
├── 化学\
├── 生物\
├── 英语\
└── 语文\
```

### 方式三：关键题截图

手机拍下某道不会的题，单独存为图片，配合错题本使用：

```
错题本\数学\函数单调性-第5题.jpg
```

然后在 `错题记录.md` 中用 `![题](../图片/函数单调性-第5题.jpg)` 引用

---

## 文件命名规范

```
[考试类型]-[日期].扩展名
```

例如：
- `月考1-2026.09.jpg`
- `期中-2026.11.pdf`
- `周测3-函数-2026.10.png`

---

## 试卷分析

每次考完试，建议同步做试卷分析：

1. **统计失分** — 每道错题扣几分？哪个知识点？
2. **归类** — 是不会做？粗心？时间不够？
3. **定计划** — 针对失分点安排后续复习
